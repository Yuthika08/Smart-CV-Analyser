# Smart-CV-Analyser
Smart CV Analyser is a menu-driven application developed using C programming and Data Structures to simplify candidate screening. It stores candidate profiles and compares their qualifications with job requirements to calculate a match score.

Features:-

*Add and display candidate CVs.

*Store candidate details using a Singly Linked List.

*Manage candidates awaiting analysis using a Queue (FIFO).

*Maintain analysis history using a Stack (LIFO).

*Compare skills, education, experience, and project requirements.

*Display candidate match scores and match status.

Technologies Used:-

*Programming Language: C

*Compiler: GCC

*Concepts: Structures, Arrays, Pointers, Linked Lists, Queues, Stacks, and Dynamic Memory Allocation.
